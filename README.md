# Gravity Tale — ステージ分割版

本を裏返すと重力が反転する、2ページ見開きの絵本ゲームです。
**ステージごとにファイルを分けてある**ので、一人が1ファイルを担当して作れます。
ステージの追加・並べ替え・他の人の作品との統合も、かんたんにできます。

---

## 1. 遊び方（動かし方）

`index.html` を**ダブルクリックしてブラウザで開く**だけです。
（サーバーは不要。ネットがなくてもフォントが変わるだけで遊べます。）

操作：← → 移動／↑・W ジャンプ／F・Space 重力反転（床・天井に立っているときだけ。空中では裏返せない）／キャラに近づいて 画面タップ・Enter で話す（↑・W はジャンプだけ。話しかけない）／会話中に S・「スキップ ≫」ボタンで会話を飛ばす（選択肢では止まる）／R・右上の「↺ やり直す」ボタンで、いまのステージを最初からやり直す（詰んだとき用）

   ├─ 04_path1.js          森の道①
   ├─ 05_meet_hood.js      赤ずきんと道連れに（会話）
   ├─ 06_wolf_talk.js      狼（会話・分岐：危険を告げるか）
   ├─ 07_crossroads.js     分かれ道（会話・分岐：近道か遠回りか）
   ├─ 08_path2.js          近道（アクション。近道を選んだときだけ）
   ├─ 09_path3.js          遠回りの道①（アクション。遠回りを選んだときだけ）

- **画像を足すときは**：`assets/character/` か `assets/background/` に置いて、`js/playlist.js`（立ち絵・背景）か `js/sprites.js`（ステージ上のキャラ）に書きます。
  大きな画像はそのままだと重いので、WebP（例：立ち絵は高さ 1024px くらい）にしておくと軽くなります。

- **ステージには2種類あります**
  - `play` … 右に進み、**右ページの右端**まで行くとページがめくれてクリア（横スクロール型）
  - `story` … ステージ上のキャラに**話しかけて**ストーリーを進め、終わったら右端へ歩いてクリア

## 3. ステージの直し方（よくある編集）

各ステージファイルの中は、だいたいこの2つです。

### 地形（足場・箱・敵）
```js
GT.defineStage('komichi1', {
  platforms:[
    // page は 'left'（左ページ）か 'right'（右ページ）
    // kind は 'ledge'（床の足場）か 'ceilingLedge'（天井の足場）
    {page:'left', x:120, y:360, w:120, h:20, kind:'ledge'},
    {page:'right',x:600, y:120, w:30,  h:170, kind:'ledge'}, // 縦長にすれば「壁」になる
  ],
  boxes:[ {x:700, y:400, w:32, h:32} ],               // 落として敵やボスに当てられる箱
  enemies:[ {page:'right', x:700, y:442, w:26, h:22, dir:-1} ], // 左右に歩く敵
});
```
座標は 900×480 の見開き。中央の綴じ目（SPINE）が x=450。左ページ=0〜450、右ページ=450〜900。

### セリフ・進行
```js
GT.registerScene({
  id:'komichi1', type:'play', stage:'komichi1', clear:'exit',
  label:'森の小道 ①',                                  // 画面上部に出る見出し
  intro:{s:'',c:'narr',t:'右へ進もう。'},               // 開始時のナレーション（省略可）
});
```
会話の1行は `{s:'話者名', c:'色の種類', t:'セリフ'}`。
`c` は `narr`(地の文) / `mari` / `hood`(赤ずきん) / `wolf` / `mother` / `granny` が使えます。

story ステージは `npcs:[{who, name, page, x, lines:[...], choices:[...], onEnd}]` を書きます。
- `who` は見た目：`'mari'` / `'hood'` / `'wolf'`
- `lines` があるキャラが「話しかけられる」キャラです
- `choices` を付けると分岐（下記）

## 4. ステージを「増やす」手順

1. `stages/` に新しいファイルを作る（既存ファイルをコピーすると早い）。
   中で `GT.defineStage('新id', {...})` と `GT.registerScene({id:'新id', ...})` を書く。
2. `index.html` の `<script src="stages/...">` の並びに、**1行コピーして**新ファイルを足す。
3. `js/playlist.js` の `GT.playlist` の好きな位置に、`'新id'` を1つ足す。

これだけで、その位置にステージが挟まります。**並べ替え**は `GT.playlist` の順番を入れ替えるだけです。

---

## 5. みんなの作品を「統合する」手順

1. それぞれが作った `stages/○○.js` を、1つの `stages/` に集める。
2. `index.html` に、集めたファイルの `<script>` 行をすべて並べる。
3. `js/playlist.js` の `GT.playlist` に、流したい順で id を並べる。

> **注意：id がかぶらないように。** 同じ `'wolf_talk'` が2つあると上書きされます。
> かぶりそうなら接頭辞を付ける（例：`ep2_wolf_talk`）と安全です。
> `GT.fillPage('key',...)` で使う本のページ key と、`js/playlist.js` の `GT.definePages` も合わせてください。

## 6. もっと凝った仕掛けを足したい人へ

ボス戦・QTE・窓のぞき映像のような「特別な仕掛け」は、`js/engine.js` を書き換えずに
**登録（register）するだけ**で足せます（例は `12_grannys_house.js` / `03_house_peek.js`）。

| したいこと | 使う関数 |
|---|---|
| 新しいシーンの種類（例：boss） | `GT.registerSceneType(type, fn)` |
| 条件で分岐する特別シーン | `GT.registerDynamic(name, fn)` + シーンに `dynamic:'name'` |
| 毎フレームの独自処理（敵のAIなど） | `GT.registerUpdate(fn)` |
| その mode 専用の更新（QTEなど） | `GT.registerModeUpdate(mode, fn)` |
| 独自の描画（キャラ・エフェクト） | `GT.registerDraw(fn, 'world'|'overlay')` |
| 会話の合図で何か起こす | `GT.registerAct(name, fn)` + セリフに `act:'name'` |
| 操作の説明の枠を出す（チュートリアル） | `GT.drawHint(x, y, 行の配列)`（例は `01_komichi1.js` / `02_komichi2.js`） |
| シーン開始時のリセット | `GT.registerSceneReset(fn)` |
| 反転キーを横取り（QTE成功判定など） | `GT.registerFlipIntercept(fn)` |

動作確認用：`GT.dbg()` `GT.getNpcs()` `GT.getBoss()` `GT.activeNpc` で中身を覗けます。

## 7. 手描きイラストを使いたいとき

キャラや背景を手描きの絵に差し替えられます（Canvas の `drawImage`）。
ステージ上のキャラの絵は `js/sprites.js` の `HOOD_SPRITE` にまとまっています（`src` が画像、`box:[左,上,右,下]` がその画像の中で使う範囲）。
画像を差し替えるときは、ここの `src` と `box` を直します（画像の大きさを変えたら、`box` も同じ割合で直す）。
左右の向き・重力反転の上下反転・伸び縮みは今の仕組みのまま使えます。
画像ができたらチャットに添付してください。組み込みます。

### 背景画像・会話の立ち絵（もう使える）
画像は `assets/background/`（背景）と `assets/character/`（立ち絵）に置き、**`js/playlist.js` の2つの表**に書くだけです。
```js
GT.stageBackgrounds = { opening:'assets/background/ohiru no mori.webp', wolf_talk:'assets/background/yuugata no mori.webp', ... };  // キーは地形の id
GT.portraits = { hood:'assets/character/水彩タッチの赤ずきん少女.webp', mother:'assets/character/水彩風の優しいお母さん.webp' }; // キーはセリフの c
```
- 背景は見開き全体に広げ、紙の色を薄くかぶせて描きます（濃さは `js/engine.js` の `BG_WASH`）。表に無いステージは背景画像なし。
- `{src:'…', page:'spread'}` と書くと、ふちを切りぬかずに**見開き全体に敷きます**（序章 `opening` がこれ）。
- 立ち絵は、そのキャラ（セリフの `c`）がしゃべっているあいだ、会話の枠の右うしろに出ます。透明背景の PNG を使ってください。
- 主人公・マリ・狼の立ち絵は、画像ができたら `mari:'assets/character/mari.webp'` のように1行足せば出ます。

## 8. 飾り（判定なしのオブジェクト）を置く・増やす

手前（プレイヤーより前）／奥（地形より後ろ）に、**当たり判定のない飾り**を置けます。
木・茂み・雲・月・岩・草・前の葉 などが最初から入っています。

- **置き方**：`editor.html` の道具箱「かざり」から選んでキャンバスに配置 → 書き出すと
  ステージに `decor:[{layer, kind, x, y, w, h}]` が入ります。`layer` は `'back'`(奥) / `'front'`(手前)。
- **仕組み**：種類は **`stages/_decor.js` 1ファイル**にまとまっています。

### 飾りを「増やす」手順（1ファイルだけ）
`stages/_decor.js` の `TYPES` に 1 行足すだけ。`index.html`・`editor.html`・`js/engine.js` は触りません。

```js
// stages/_decor.js の TYPES に追加する例
flower: { label:'花', layer:'front', w:30, h:40, draw(ctx,x,y,w,h){
  ctx.fillStyle='#c98bb0';
  ctx.beginPath(); ctx.arc(x+w/2, y+h*0.3, w*0.4, 0, Math.PI*2); ctx.fill();
  ctx.strokeStyle='#5e6e4b'; ctx.lineWidth=3;
  ctx.beginPath(); ctx.moveTo(x+w/2,y+h*0.3); ctx.lineTo(x+w/2,y+h); ctx.stroke();
}},
```

保存して `index.html` / `editor.html` を開き直すと、ゲームにもエディタの道具箱にも自動で出ます。

### フラットな絵本ふうにする（序章 `00_opening.js` の見た目）
輪郭線なしの平らな色で描く飾り `treeFlat`（木）/ `bushFlat`（茂み）/ `rockFlat`（岩）/ `grassFlat`（草）/ `fernFlat`（前の葉）があります。
足場も同じ雰囲気にするには、ステージファイルに `GT.setLedgeStyle('ステージid','flat');` を1行書きます。

### 足場を森の絵にする（`GTDecor.forest`）
`_decor.js` には、**足場の上に重ねて描く森の絵**も入っています（当たり判定は変わりません）。
森の小道①②（`01_komichi1.js` / `02_komichi2.js`）と、森の道①・近道・遠回りの道①②（`04`・`08`・`09`・`10`）がこれを使っています。
```js
const F=GTDecor.forest, P=i=>GT.STAGE_DEFS['ステージid'].platforms[i];
F.rock([P(3),P(4)], 7);   // 苔むした岩（重なった足場をひとつの岩に）  ほかに crown(葉の茂み) / trunk(幹) / vine(つる) / log(丸太)
F.crate(GT.boxes[0]);     // 木目のある木箱
F.ground({flowers:[[x,色0〜3],...], mushrooms:[[x,大きさ],...]});  F.air();  // 床の花・ちょうちょ・舞う葉
```

> 仕組みのメモ：`js/engine.js` に「奥（最背面）レイヤー」の描画口を1つ足しました
> （`GT.registerDraw(fn, 'back')`）。飾りの手前側は従来の `'overlay'` を使っています。

## 9. クリア判定（理論上クリアできるか調べる）

`editor.html` の **🔍 クリア判定** を押すと、いま作っているステージがクリアできるかを自動で調べます。

- ✅ **クリアできます** … 見つかった道すじを青い線で描きます（⇅ は本を裏返す場所）。**▶ ルートを再生** で動きを確認できます。
- ❌ **クリアできません** … 通り道がふさがっている、旗や人物がいない、など理由を出します。
- ⚠ **判定しきれませんでした** … 上限まで試しても見つからなかったとき。無理か、とても細かい操作が必要なステージです。**もっと調べる** で範囲を広げられます。

しくみ：エンジンと同じ物理（重力・反転・ジャンプ・箱・敵・沼・会話）で、
「←→・止まる × ジャンプ × 裏返す」を 0.1 秒きざみで組み合わせて探します。
ボス戦など、ステージに後から足した特別な仕掛けは考えに入りません。
**本を裏返すのは、床（反転中は天井）に立っているときだけ**で調べます。
空中で裏返しを連打して浮き続ける裏技は使わないので、「浮遊しないと届かない」ステージはクリアできない判定になります。

> 注意：判定用の物理は `editor.html` の中に **engine.js の写し**として入っています（`GTSolver`）。
> `js/engine.js` の物理や数値（重力・速さ・ジャンプ力・沼など）を変えたら、こちらも同じように直してください。

## 10. ミッション（クリアしないと次のページへ進めない）

ステージに「ミッション」を付けると、**終わるまで右端（またはゴール旗）が開きません**。
画面の上に進み具合（例：`ミッション ★ 1/3 敵 0/2`）が出て、達成すると「ミッション達成！」と表示され、右端の扉が開きます。

| ミッション | 内容 |
|---|---|
| アイテムを全部集める | 置いた **アイテム（星）** を全部取る |
| 敵を全部倒す | **木の箱を落として** 敵を全員倒す（箱が無いと倒せません） |

- **エディタで**：道具箱の「アイテム（星）」で星を置き、右の「ステージ設定 → ミッション」にチェックを入れる。
- **書き出すと** こうなります：
```js
GT.defineStage('id', {
  ...,
  items:[ {page:'left', x:300, y:420, w:24, h:24} ],   // 集める星
  mission:['items', 'enemies'],                        // 両方なら2つ、片方なら1つ
});
```
- 星の当たり判定は、見た目の星形に合わせて **四角の内側 20%** にしぼってあります（角をかすっただけでは取れません）。
- story ステージでも使えます（人物と話し、さらにミッションも終えると右端が開きます）。
- 🔍 **クリア判定** もミッション込みで調べます（星に届かない・箱が無い、なども教えてくれます）。

## 11. メニュー画面とセーブ（`js/menu.js`）

ゲームを開くと、まずメニュー（もくじ）が出ます。ゲーム中は左上の **≡ メニュー** か **Esc** で開けます（開いているあいだは止まります）。

| 項目 | 内容 |
|---|---|
| つづける | ゲーム中に開いたときだけ出る。そのまま再開 |
| はじめから | 序章から。分岐フラグと本のページも最初にもどる |
| つづきから | 最後に来たステージから |
| ステージをえらぶ | 一度来たステージから遊べる（まだのステージは ？？？） |
| 本を読みかえす / あそびかた | 本のページ一覧・操作の説明 |

- 進み具合は、**ステージが始まるたびにブラウザへ自動でセーブ**されます（`localStorage`）。そのステージに来たときのフラグと本のページも一緒に記録します。
- ステージ一覧の名前は、各ステージの `label` を使います。`label` の無いシーンは `js/menu.js` の `NAMES` で決めます。
- タイトルの背景は `js/menu.js` の `TITLE_BG` で変えられます。
- `js/engine.js` に足した口：`GT.onSceneStart(fn)` / `GT.jumpToScene(番号, ページ)` / `GT.paused` / `GT.getPageNo()`。`GT.showMenu` があると、起動時にそこから始まります。

### 本を読みかえす画面（`js/bookview.js`）
見開きの本で、1枚ずつページをめくって読みます。最初の左ページはとびら（題名と、埋まったページの数）、そのあと `GT.definePages` の順に1ページずつ並び、まだ埋まっていないページは虫食いの白紙です。
◀ ▶ ボタン・ページの左右をクリック・← → キー・スワイプでめくり、Esc か「閉じる」で閉じます（開いているあいだゲームは止まる）。めくる速さは `TURN_MS` で変えられます。

埋まったページには、その場面の挿絵が入ります（`js/bookart.js`）。背景画像と立ち絵を組み合わせ、少年・マリ・狼・家・部屋は手描きふうに描いています。
分岐で絵も変わります（狼に告げたか・戸口で止めたか・おばあさんが無事か・3つの結末）。
挿絵を足す・変えるときは、`js/bookart.js` の `SCENES` にページの key と描く関数を書くだけです。

### 木の絵（`GTDecor.paint`）
木はすべて `stages/_decor.js` の同じ道具で描いています（葉のかたまりの陰影・インクの輪郭・木の皮のすじ・根・ふし・苔・枝）。
```js
GTDecor.paint.canopy(ctx, [{x,y,rx,ry}, ...], 種);              // 葉の茂み（だ円のかたまり。{rect:true,x,y,w,h} なら足場の四角にそう）
GTDecor.paint.trunk(ctx, x, 上, 下, 幅, 種, {hollow, branches}); // 幹（hollow でうろ、branches で枝）
GTDecor.paint.grass(ctx, x, y, 幅, 高さ, 種, {flowers});       // 草のしげみ（奥と手前の2層の葉・穂・小さな花。flowers:false で花なし）
GTDecor.paint.bush(ctx, x, y, 幅, 高さ, 種, {berries:'#色'});  // 茂み（地面にすわる葉の山＋根元の草。berries で実）
GTDecor.paint.fern(ctx, x, y, 幅, 高さ, 種);                    // シダ（弓なりの葉軸に小葉がならぶ）
GTDecor.paint.flower(ctx, x, 地面のy, 大きさ, 色0〜3, 種);       // 花（茎・葉・花びら・しべ）
```
一度描いた木は画像として取っておくので、たくさん置いても重くなりにくいです。飾りの「木」・森の絵の `trunk` / `crown`・序章のマリの木・狼の森の爪あとの木が、これを使っています。

## 12. 人物も重力にしたがう・何回も逆さにすると怒られる

- 赤ずきん・マリ・狼・おばあさんも、いるページの重力の向きに落ちます（天井にいるときは上下さかさま）。しくみは `js/engine.js` の `GT.fallBody(b, dt)`。
- 何回も逆さにすると、吹き出しで怒られます（1回目は何も言わない。回数が増えるほど怒る。しばらく反転しないとおさまる）。
  セリフは `js/engine.js` の `GT.GRUMBLE` で、キャラごとに5段階（だんだん怒る順）。ステージ独自の人物には `GT.grumble(b, 'hood')` を呼ぶと同じしくみが使えます。
