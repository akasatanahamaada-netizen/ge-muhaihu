# Gravity Tales　第一章「赤い頭巾」

**本を裏返すと、そのページの重力が反転する。**
見開きの絵本の中を歩き、童話「赤ずきん」の結末を自分の手で書きかえていく、2D の謎解きアクション・アドベンチャーです。

記憶をなくした少年は、暗い森で一冊の本を拾います。本の中は童話の世界。
ところどころ虫に食われたページを埋めながら、赤ずきんと出会い、狼と出会い――
どこで何を見て、だれに何を話すかで、物語の結末が変わります。

---

## 遊び方

`index.html` をブラウザで開くだけで遊べます（インストール・サーバーは不要）。
パソコン（キーボード）でも、スマートフォン・タブレット（画面のボタン。横向きがおすすめ）でも遊べます。

### 操作

| | キーボード | タッチ |
|---|---|---|
| 歩く | ← → | ◀ ▶ |
| ジャンプ | ↑ / W | ▲ |
| **本を裏返す（重力の反転）** | **F / Space** | **Flip** |
| 話しかける・調べる・会話を進める | Enter | 画面をタップ |
| 会話を飛ばす | S | Skip ≫ |
| ステージをやり直す | R | ↺ Reset（2回押す） |
| メニュー | Esc | menu |

- 本を裏返せるのは、床（反転しているときは天井）に立っているときだけです。
- 右のページの右の端まで進むと、ページがめくれて物語が進みます。
- 画面の下の「本を開く」で、これまでのページを読み返せます。本の各ページのボタンから、そのステージをやり直すこともできます。
- 進み具合は、ステージが始まるたびにブラウザへ自動でセーブされます（メニューの Continue で続きから）。

## 見どころ

- **左右のページで、重力が別々**
  本を裏返すと、いま立っているページの重力だけが反転します。
  左のページは天井へ、右のページは床へ――木箱を天井と床へ運んで踏み台にしたり、天井を歩いて水たまりを越えたり。
  赤ずきんや狼も、ページの重力にしたがって落ちます（何回も逆さにすると、怒られます）。
- **見て、話して、結末を変える**
  狼の足あと、木の幹の爪あと、狼のおなかの音……。まわりをよく調べたかどうかで、選べる言葉が変わります。
  「狼のことを赤ずきんに伝えるか」「いばらの近道を行くか、赤ずきんと遠回りをするか」「家の前で赤ずきんを止めるか」。
  選んだ道によって、**3つの結末**にたどり着きます。
  - 結末A「分けあったカスタード」
  - 結末B「残されたストール」
  - 結末C「ベッドの上の赤い頭巾」
- **本が、物語を記録する**
  ステージで「お話のかけら」を集めると、虫食いのページが文章と挿絵で埋まっていきます。
  挿絵は、選んだ分岐によって変わります。見たエンディングは、本の第一章のとびらに記録されます。
- **狼とのボス戦**
  おばあさんの家では、本を裏返して家具を天井へ飛ばし、狼の頭上に落として戦います。

### 物語の流れ

```
序章　暗い森で目覚める → マリと出会う → 森の小道（本の使いかたを覚える）→ 森の出口
第一章　赤ずきんの家（窓をのぞく）→ 森の道 → 赤ずきんと出会う → 森の崖 → 狼と出会う
　　　→ 分かれ道 ┬ 近道（いばらの道）……………………… ┐
　　　　　　　　 └ 遠回り（お花畑・遠回りの道）… ┴→ おばあさんの家の前 → おばあさんの家（ボス戦）
　　　→ 結末A／B／C → 森の出口でマリと話す
```

### ステージのしくみ

各ステージファイルには、地形（`GT.defineStage`）と場面（`GT.registerScene`）を書きます。

```js
GT.defineStage('cliff', {
  platforms:[ {page:'left', x:60, y:150, w:110, h:24, kind:'ledge'} ],   // 足場（kind:'ceilingLedge' で天井の足場）
  boxes:[ {x:100, y:110, w:40, h:40} ],                                   // 木箱（押せる・落として敵に当てられる）
  enemies:[], items:[ {page:'left', x:300, y:428, w:32, h:32} ],          // 敵・お話のかけら
  mission:['items'], itemsOptional:true,                                  // 右の端を開ける条件
});
GT.registerScene({
  id:'cliff', type:'play', stage:'cliff', clear:'exit', label:'第一章 ── 森の崖',
  companion:'hood',                                                       // 赤ずきんがついてくる
  intro:[ {s:'赤ずきん', c:'hood', t:'わあ、高い崖……。'} ],              // はじめの会話
});
```

- 画面は 900×480 の見開き。まん中の綴じ目が x=450（左ページ 0〜450／右ページ 450〜900）。
- 場面の種類：`play`（右の端まで進むとクリア）／`story`（人物に話しかけて進める。`npcs:[{who, name, x, lines, choices, onEnd}]`）。
- 会話の1行は `{s:'話す人', c:'色の種類', t:'セリフ', f:'表情', act:'合図'}`。
  `c` は `narr`（語り）/ `boy` / `mari` / `hood` / `wolf` / `granny` / `mother`。
- 分岐は `choices:[{label, set, after, when}]` で選択肢を出し、`GT.flags` に記録します。
- 特別な仕掛け（ボス戦・QTE・窓のぞきなど）は、`js/engine/` を書きかえずに登録で足せます：
  `GT.registerUpdate` / `GT.registerDraw` / `GT.registerAct` / `GT.registerSceneType` / `GT.registerDynamic` / `GT.registerFlipIntercept` など。
- ステージを足すときは、`stages/` にファイルを作り、`index.html` に `<script>` を1行、`js/playlist.js` の `GT.playlist` に id を1つ足します。

### ステージエディタ（`editor.html`）

足場・木箱・敵・アイテム・飾りを置いて、その場でテストプレイできます。
**クリア判定**を押すと、「←→・止まる × ジャンプ × 本を裏返す」を 0.1 秒きざみで組み合わせて、そのステージがクリアできるかを自動で調べ、見つかった道すじを描きます。
（判定用の物理は `editor.html` の中に `js/engine/physics.js` の写しとして入っています。重力・速さ・ジャンプ力などを変えたら、こちらも合わせて直します。ボス戦など、あとから足した特別な仕掛けは判定に入りません。）
